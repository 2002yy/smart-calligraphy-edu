## 3. 首版核心数据表

### 3.1 用户表 `users`

核心字段：

- `id`
- `username`
- `password_hash`
- `name`
- `role`
- `school_name`
- `created_at`

### 3.2 课程表 `courses`

核心字段：

- `id`
- `name`
- `term`
- `description`
- `teacher_id`
- `status`
- `created_at`

### 3.3 班级表 `classes`

核心字段：

- `course_id`

- `created_at`

## 5. 实现建议

- 首版先保证 `auth / tasks / homework / evaluation / reviews / dashboard / reports` 闭环跑通
- 二阶段再扩展推荐、资源库、问答和展示能力
- 表设计优先服务联调与演示，不提前堆积复杂字段
