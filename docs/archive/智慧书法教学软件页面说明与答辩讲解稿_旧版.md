# 智慧书法教学软件页面说明与答辩讲解稿

## 1. 使用说明

这份文档用于配合页面原型和答辩 PPT 使用。  
每个页面统一拆分为四部分：

- `页面说明`：这个页面解决什么问题
- `页面结构`：页面由哪些模块组成
- `交互说明`：用户如何在这个页面完成操作
- `讲解话术`：答辩时可以直接说的内容

建议在答辩 PPT 中优先展示以下页面：

1. 学生首页
2. 任务详情页
3. 上传评测页
4. 评测结果页
5. 教师首页看板
6. 作业批阅页
7. 学情分析页

这 7 个页面最能讲清产品闭环。

## 2. 学生端页面

## 2.1 学生首页

### 页面说明

学生首页是整个学生端的总入口，承担三个作用：

- 告诉学生今天该做什么
- 告诉学生最近练得怎么样
- 告诉学生下一步应该继续练什么

这个页面解决的是“学生一打开软件，不知道从哪里开始”的问题。

### 页面结构

- 顶部信息区：课程名称、连续练习天数、今日任务提醒
- 今日任务卡片：展示最紧急或最重要的训练任务
- 成长数据卡片：成长值、本周进步、完成次数
- 最近反馈区：展示上一次评分结果和问题摘要
- 推荐训练区：系统根据最近问题推荐专项训练
- 快捷入口区：字帖馆、拍照评测、成长档案

### 交互说明

1. 学生进入首页后，优先看到今日任务
2. 点击任务卡片，进入任务详情页
3. 点击最近反馈，可查看上一次评测结果
4. 点击推荐训练，可进入专项练习页面
5. 点击底部导航，可切换字帖馆、评测、我的

### 讲解话术

这个页面是学生端的起点，我们重点不是做一个传统的信息首页，而是做一个任务驱动的学习首页。  
学生打开软件后，首先看到的是今天要完成的训练任务，其次可以看到自己最近一次书写反馈，比如系统指出他的重心偏左、右部偏窄。  
这样学生不会陷入盲目练习，而是能明确知道自己今天练什么、为什么练、练完之后往哪里走。

## 2.2 任务详情页

### 页面说明

任务详情页的核心目标是让学生明确理解教师要求，避免“任务看不懂、提交不规范、练习没有重点”。

### 页面结构

- 任务标题与截止时间
- 教师信息与课程信息
- 任务目标说明
- 本次练习字或专项内容
- 评分重点说明
- 提交格式要求
- 两个关键按钮：查看范字、开始练习

### 交互说明

1. 学生从首页点击某个任务进入本页
2. 浏览任务目标和示范字
3. 点击“查看范字”进入单字详情页
4. 点击“笔顺演示”进入笔顺教学页
5. 完成练习后点击“去提交”进入上传评测页

### 讲解话术

这个页面体现的是教学规范化。  
在传统课后练习中，学生常常只知道“回去写几个字”，但不知道老师究竟看重什么。  
所以我们在页面里把任务目标、练习字、评分重点和提交要求全部结构化展示出来。  
这样教师布置任务更清晰，学生执行任务也更明确。

## 2.3 字帖馆检索页

### 页面说明

字帖馆是平台的资源底座，主要解决“学生想查资料，但资源分散、检索困难”的问题。

### 页面结构

- 顶部搜索框
- 分类筛选栏：书体、书法家、碑帖
- 热门推荐或最近浏览
- 资源卡片列表
- 单字检索与名家作品入口

### 交互说明

1. 学生输入单字、书法家或碑帖名称进行检索
2. 使用书体标签过滤检索结果
3. 点击资源卡片进入单字详情页或碑帖详情页
4. 在浏览过程中可收藏或加入练习

### 讲解话术

字帖馆的作用不是单纯堆资料，而是把资源变成可检索、可调用、可进入练习流程的教学底座。  
学生既可以查“永”这个字，也可以查某位书法家的风格，还可以直接从资源页进入练习。  
这样资源就不再是孤立展示，而是和教学过程打通了。

## 2.4 单字详情页

### 页面说明

单字详情页是从“看资源”走向“学结构、去练习”的关键过渡页。

### 页面结构

- 大尺寸范字展示区
- 书法家、书体、碑帖信息
- 字义与基础介绍
- 结构解析区
- 相似字推荐区
- 操作按钮：笔顺动画、开始临摹

### 交互说明

1. 学生从字帖馆进入单字详情页
2. 放大查看标准范字细节
3. 阅读结构分析和书体说明
4. 查看相似字，拓展专项训练
5. 点击“笔顺动画”或“开始临摹”进入下一步

### 讲解话术

我们把单字详情页设计成一个“微型教学页”。  
在这个页面里，学生不仅能看到范字，还能看到这个字的结构特点，比如主笔方向、重心位置和常见错误。  
这比单纯展示一张字帖更有教学价值，因为它把静态资源转化成了可理解、可训练的学习内容。

## 2.5 笔顺演示页

### 页面说明

笔顺演示页主要解决“学生会看字，但不会落笔”的问题，是初学者最需要的引导页面之一。

### 页面结构

- 动态笔顺展示区
- 当前笔画步骤提示
- 分步讲解文字
- 模式切换：描红模式、骨架模式
- 步骤列表区

### 交互说明

1. 学生点击播放按钮观看完整笔顺
2. 可切换为逐笔播放模式
3. 可查看每一步的讲解说明
4. 可进入描红模式进行辅助练习

### 讲解话术

这个页面体现的是“教会学生怎么写”，而不是只告诉学生“这个字长什么样”。  
我们引入笔顺动画、逐笔讲解和描红模式，就是为了帮助没有书法基础的学生也能快速进入练习状态。  
对于书法教学来说，这一步是把观察变成动作学习的关键环节。

## 2.6 上传评测页

### 页面说明

上传评测页负责承接线下书写和线上智能分析，是整个闭环中的数据入口。

### 页面结构

- 相机拍照或相册导入入口
- 图片预览区
- 自动裁剪与透视矫正区
- 图片质量检查提示
- 提交按钮

### 交互说明

1. 学生拍照上传书写作品
2. 系统自动识别纸张边缘和书写区域
3. 系统完成裁剪、校正和清晰度检查
4. 学生确认图片无误后提交智能评测

### 讲解话术

上传评测页看似简单，但它决定了后面 AI 评分是否可靠。  
所以我们在这里加入了自动裁剪、透视校正和清晰度检查，尽量减少拍照角度和光线带来的干扰。  
这样系统后续做结构评分时，结果会更稳定、更可信。

## 2.7 评测结果页

### 页面说明

评测结果页是整个产品最核心的页面，也是答辩中必须重点展示的页面。  
这个页面的目标不是只显示一个分数，而是让学生理解：

- 自己写得哪里有问题
- 问题具体表现在哪里
- 下一步应该继续练什么

### 页面结构

- 顶部综合评分区
- 学生作品与标准范字并排展示
- 半透明叠加对比区
- 分项评分区：结构、重心、笔顺等
- 问题标签区
- 文字解释区
- 推荐练习字区
- 操作按钮：再次练习、保存报告

### 交互说明

1. 学生提交作业后自动跳转至本页
2. 首先看到综合得分和简要结论
3. 然后对比自己的作品和标准范字
4. 点击或查看问题标签，理解具体错误
5. 查看系统生成的练习建议
6. 选择再次练习或保存报告

### 讲解话术

这是我们产品和普通字帖平台最本质的区别。  
普通平台往往只能给资源，而我们的系统会对学生的作品进行智能分析。  
在这个页面里，学生不仅能看到一个分数，更能看到自己和标准范字的差异、问题标签以及系统推荐的下一步练习内容。  
也就是说，平台真正承担了“评”和“导”的功能，而不只是“展示”的功能。

## 2.8 成长档案页

### 页面说明

成长档案页的目标是把一次次练习沉淀成长期可视化成果，增强学生成就感，也为教师和项目汇报提供数据支持。

### 页面结构

- 累计练习次数
- 平均分变化趋势图
- 连续打卡天数
- 问题变化分析
- 历史作品记录
- 阶段成就或勋章展示

### 交互说明

1. 学生在底部导航点击“我的”
2. 查看近期成绩趋势和训练记录
3. 回看历史作品和历次评测结果
4. 看到常见问题是否正在改善

### 讲解话术

我们希望学生看到自己的进步，而不只是一次次被打分。  
所以平台把每次训练、每次评分和每次问题变化都沉淀成成长档案。  
这不仅能增强学生的学习动力，也能帮助教师和项目团队更清楚地证明教学效果。

## 3. 教师端页面

## 3.1 教师首页 / 班级看板

### 页面说明

教师首页是教师端最重要的页面，核心作用是帮助教师在最短时间内掌握班级整体状态。

### 页面结构

- 当前课程信息
- 待批阅数量
- 班级人数、提交率、平均分
- 共性问题 Top5
- 重点关注学生
- 进步最快学生
- 近几周趋势图

### 交互说明

1. 教师登录后默认进入看板页
2. 快速查看班级整体完成情况
3. 点击待批阅进入作业批阅页
4. 点击共性问题进入学情分析页
5. 点击重点学生查看其个人情况

### 讲解话术

这个页面体现的是平台对教师的价值。  
传统书法教学中，教师往往只能逐份作业去看，很难快速把握班级共性问题。  
而在我们的教师看板里，教师一登录就能看到提交率、平均分、主要问题和重点学生。  
这就把过去依赖经验的教学判断，变成了数据可视化支持下的精准教学。

## 3.2 课程管理页

### 页面说明

课程管理页解决的是“教师如何组织教学”这一问题，是教学流程的起点。

### 页面结构

- 课程列表区
- 班级列表区
- 学生名单区
- 加入方式或邀请码
- 操作按钮：新建课程、新建班级、导入学生

### 交互说明

1. 教师创建课程和班级
2. 导入学生名单或生成加入方式
3. 进入某个班级查看成员和进度
4. 从课程页进入任务发布页

### 讲解话术

这个页面承接的是教学组织工作。  
平台不仅服务学生练习，还要服务教师建课、建班和管理成员。  
只有先把课程结构搭建起来，后面的任务布置、作业提交和数据分析才能形成完整闭环。

## 3.3 任务发布页

### 页面说明

任务发布页的目标是让教师能快速、规范地布置一项书法训练任务。

### 页面结构

- 任务标题
- 课程与班级选择
- 截止时间设置
- 练习字输入区
- 评分权重设置
- 提交说明设置
- 操作按钮：预览任务、发布任务

### 交互说明

1. 教师输入任务名称并选择目标班级
2. 填写练习字或调用资源库中的练习模板
3. 设置结构、重心、笔顺等评分权重
4. 设置提交要求
5. 点击发布，任务同步到学生端首页

### 讲解话术

在这个页面里，教师可以把一项原本口头布置的练习任务，变成结构化、标准化的数字任务。  
教师不仅能布置内容，还能明确本次训练的评价重点。  
这能让学生更清楚任务要求，也能让平台后续更准确地进行智能评分和结果反馈。

## 3.4 作业批阅页

### 页面说明

作业批阅页是教师端第二个最核心的页面。  
它解决的问题是：教师如何在保证专业性的同时，提高批改效率。

### 页面结构

- 当前学生与任务信息
- 学生作品图
- 标准范字图
- AI 分项评分
- AI 问题建议
- 教师点评输入区
- 操作按钮：上一份、下一份、确认批阅、退回重交

### 交互说明

1. 教师从待批阅列表进入本页
2. 查看学生作品与范字对比
3. 查看系统自动评分与问题说明
4. 选择接受、修改或补充 AI 建议
5. 写下教师点评并确认批阅
6. 切换到下一份作业

### 讲解话术

这个页面体现的是“AI 辅助教师”，而不是“AI 替代教师”。  
系统会先做基础评分和问题判断，帮助教师节省时间，但最终教师仍然拥有点评和复核权。  
这样既提高了效率，也保留了书法教学中非常重要的专业判断和个性化指导。

## 3.5 学情分析页

### 页面说明

学情分析页从班级维度对学生学习状态进行聚合分析，是平台数据价值的集中体现。

### 页面结构

- 学生分层统计
- 问题热力图
- 共性问题排行
- 趋势分析图
- 重点学生列表

### 交互说明

1. 教师进入学情分析页查看班级整体表现
2. 通过图表看到当前最常见的结构问题
3. 查看不同学生层级分布
4. 找到需要重点辅导的学生群体

### 讲解话术

这个页面说明我们的平台不仅能看单份作业，还能看整个班级的学习规律。  
教师可以从这里看到哪些问题最常见、哪些学生在稳步提升、哪些学生需要重点辅导。  
这意味着平台已经从单次评分工具，升级成了真正的数据化教学辅助系统。

## 3.6 数据报告页

### 页面说明

数据报告页用于把教学过程中的数据和成果沉淀成可导出的报告材料，方便课程总结、项目答辩和推广应用。

### 页面结构

- 课程总览数据
- 覆盖人数与完成率
- 平均提分情况
- 优秀案例摘要
- 报告模板区
- 导出按钮

### 交互说明

1. 教师或管理员选择某门课程或某个周期
2. 系统自动汇总关键数据
3. 教师预览报告内容
4. 导出 PDF、图片或汇报素材

### 讲解话术

这个页面体现的是项目成果沉淀能力。  
对于大创项目来说，我们不仅要做一个能用的软件，还要形成可展示、可推广、可复用的成果。  
通过这个模块，平台能够直接生成课程报告、个人成长报告和答辩数据摘要，帮助项目组提升展示效率和成果转化能力。

## 5. PPT 使用建议

如果你准备做答辩 PPT，可以按下面方式组织。

### PPT 单页结构模板

- 页面名称
- 页面截图
- 页面作用一句话
- 关键模块 3 点
- 核心价值 1 句话

### 示例：评测结果页

- 页面名称：智能评测结果页
- 页面作用：对学生书写结果进行结构化分析与纠错引导
- 关键模块：
  - 学生作品与范字对照
  - 问题标签与分项评分
  - 推荐练习与下一步任务
- 核心价值：
  - 实现从“展示资源”到“智能教学反馈”的跃迁

## 6. 一句话收束

这套页面设计的重点不是把功能堆满，而是通过“学生学习闭环 + 教师教学闭环”两条主线，把智慧书法教学的价值讲清楚、讲完整、讲得能落地。
