## 五、推荐启动顺序

按这个顺序最稳：

1. 先启动 `api-server`
2. 再启动 `teacher-web`
3. 最后启动 `student-app`

原因：

- 前端一打开就会请求后端接口
- 如果后端没先启动，前端页面会提示接口连接失败
- 先把后端稳定跑起来，双端联调会顺很多

## 九、如果启动失败，优先检查这几项

### 1. 后端没启动

表现：

- 页面打不开数据
- 控制台提示接口报错

处理：

- 先确认 `uvicorn app.main:app --reload` 是否还在运行

### 2. 前端依赖没装

表现：

- 执行 `npm run dev` 报缺包

处理：

- 先执行 `npm install`

### 3. 端口变化

表现：

- 地址不是 `5173` 或 `5174`

处理：

- 以终端输出的 Vite 本地地址为准

### 4. 接口地址不一致

表现：

- 前端能打开，但请求失败

处理：

- 检查 `.env.example` 或本地环境变量中 `VITE_API_BASE_URL`
- 确认它指向 `http://127.0.0.1:8000`
