# 项目初始化命令清单

## 1. 总体说明

下面的命令清单用于在 `VS Code` 终端中初始化各子项目。  
由于你当前已经有了目录骨架，这里更偏向“接下来应该怎么继续初始化和运行”。

建议在项目根目录 `c:\Users\96967\Desktop\大创\code` 下执行。

## 2. 学生端 `student-app`

### 推荐方式

如果你使用 HBuilderX 管理 uni-app，建议：

1. 先保留当前 `student-app/` 目录
2. 用 HBuilderX 新建 uni-app 项目
3. 再把生成内容复制或覆盖到 `student-app/`

### 如果你使用命令行方式

可以先进入目录：

```powershell
cd c:\Users\96967\Desktop\大创\code\student-app
```

后续根据你使用的 uni-app CLI 方式补充初始化。

当前阶段建议先做：

- 页面结构
- mock 数据
- 接口占位

## 3. 教师端 `teacher-web`

进入目录：

```powershell
cd c:\Users\96967\Desktop\大创\code\teacher-web
```

安装依赖：

```powershell
npm install
```

建议补充安装：

```powershell
npm install vue vue-router pinia axios element-plus echarts
```

如果后续接 TypeScript 支持较完整的 Vite 项目，可重新执行：

```powershell
npm create vite@latest
```

启动开发服务：

```powershell
npm run dev
```

## 4. 业务后端 `api-server`

进入目录：

```powershell
cd c:\Users\96967\Desktop\大创\code\api-server
```

创建虚拟环境：

```powershell
python -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
pip install -r requirements.txt
```

启动服务：

```powershell
uvicorn app.main:app --reload --port 8000
```

打开接口文档：

```text
http://127.0.0.1:8000/docs
```

## 6. 推荐启动顺序

建议按下面顺序启动：

1. `api-server`
2. `ai-service`
3. `teacher-web`
4. `student-app`

原因：

- 后端和 AI 服务先跑起来，前端更方便联调
- 教师端和学生端再逐步接真实接口
