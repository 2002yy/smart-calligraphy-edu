# 智慧书法教学软件本地启动与答辩演示操作稿

这是一份给“第一次运行项目的人”准备的操作稿。你不用懂编程，只要严格按顺序操作，就能把后端、教师端、学生端依次启动起来，并完成一遍答辩演示。

## 一、先确认你现在在哪个文件夹

1. 打开 `cmd` 黑色终端窗口。
2. 输入下面这条命令，然后按回车：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
```

3. 如果你看到命令行前面变成：

```cmd
c:\Users\96967\Desktop\大创\code>
```

就说明你已经进入了正确目录。

## 二、第一次运行时，先安装前端依赖

如果你之前已经成功跑过教师端和学生端，这一步可以跳过。

在当前窗口输入：

```cmd
scripts\install-frontends.cmd
```

看到安装完成后，再进行下一步。

## 三、启动顺序一定要这样

必须按下面顺序启动：

1. 先启动后端 `api-server`
2. 再启动教师端 `teacher-web`
3. 最后启动学生端 `student-app`

原因很简单：

- 后端负责提供数据接口
- 教师端和学生端都要连接后端
- 如果后端没开，前端页面会提示接口连接失败

## 四、打开第 1 个终端，启动后端

1. 新开一个 `cmd` 窗口。
2. 输入：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
scripts\start-api-server.cmd
```

3. 看到类似下面内容，说明后端启动成功：

```text
Uvicorn running on http://127.0.0.1:8000
```

4. 这个窗口不要关掉，保持开着。

## 五、打开第 2 个终端，启动教师端

1. 再新开一个 `cmd` 窗口。
2. 输入：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
scripts\start-teacher-web.cmd
```

3. 启动成功后，你会看到类似：

```text
Local: http://localhost:5173/
```

有时端口也可能不是 `5173`，例如 `5174`、`5175`，这都正常，请以终端里显示的地址为准。

4. 这个窗口也不要关掉。

## 六、打开第 3 个终端，启动学生端

1. 再新开一个 `cmd` 窗口。
2. 输入：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
scripts\start-student-app.cmd
```

3. 启动成功后，你会看到类似：

```text
Local: http://localhost:5174/
```

如果端口不是 `5174`，也请以终端里实际显示的地址为准。

4. 这个窗口同样不要关掉。

## 七、浏览器里分别打开什么地址

当三端都启动后，打开浏览器：

1. 后端 Swagger 文档：

```text
http://127.0.0.1:8000/docs
```

2. 教师端页面：

```text
http://localhost:5173/
```

如果教师端终端显示的不是 `5173`，就用它实际显示的地址。

3. 学生端页面：

```text
http://localhost:5174/
```

如果学生端终端显示的不是 `5174`，也用实际显示的地址。

## 八、答辩演示时，推荐按这个顺序操作

### 第一步：先展示后端已经启动

打开：

```text
http://127.0.0.1:8000/docs
```

讲解重点：

- 这是系统后端接口文档
- 教师端和学生端都连接这套接口
- 系统已经具备登录、课程、班级、任务、作业、评测、报告等完整链路

### 第二步：打开教师端，先登录

教师端默认账号可以直接填：

- 账号：`teacher01`
- 密码：`123456`

登录后，建议这样讲：

- 教师端是整个教学闭环的管理入口
- 可以完成课程创建、班级创建、任务发布和结果复盘

### 第三步：教师端创建课程

进入“课程班级”页面，操作顺序：

1. 填课程名称
2. 填开课学期
3. 填课程说明
4. 点击“创建课程”

建议演示用内容：

- 课程名称：`智慧书法素养提升课`
- 开课学期：`2026春季`
- 课程说明：`用于展示书法练习、AI评测与教学反馈闭环`

### 第四步：教师端创建班级

继续在同一页：

1. 选择刚创建的课程
2. 填班级名称
3. 可填写邀请码，也可让系统自动生成
4. 点击“创建班级”

建议演示用内容：

- 班级名称：`2026春季实验班`
- 邀请码：`CALLI2026`

### 第五步：教师端发布任务

进入“任务编排”页面，按下面填写：

1. 选择课程
2. 选择班级
3. 填任务标题
4. 填练习字
5. 填任务说明
6. 点击“发布任务”

建议演示用内容：

- 任务标题：`欧楷结构与重心训练`
- 练习字：`永、木、中、人`
- 任务说明：`重点观察结构均衡、重心稳定和基本笔顺规范`

讲解重点：

- 教师可以把训练目标直接结构化发布给学生
- 后续学生提交后，结果会自动回流到教师端

### 第六步：切到学生端并登录

学生端默认账号可以直接填：

- 账号：`student01`
- 密码：`123456`

讲解重点：

- 学生端围绕任务领取、作业提交、AI评测和成长沉淀展开

### 第七步：学生加入班级

在学生端左侧：

1. 选择班级
2. 输入邀请码：`CALLI2026`
3. 点击“加入班级”

### 第八步：学生查看任务

进入“任务中心”，点击刚才教师端发布的任务。

讲解重点：

- 学生可以明确看到训练标题、练习字、评分权重、截止时间
- 任务目标清晰，不是单纯发通知

### 第九步：学生提交作业并发起评测

进入“提交评测”页面：

1. 确认已经选中任务
2. 使用页面默认的示例图片地址
3. 点击“提交作业”
4. 再点击“发起评测”

讲解重点：

- 学生提交作品后，系统会立即生成 AI 评测结果
- 页面会展示总分、分项得分、问题标签和练习建议

### 第十步：学生查看成长档案

进入“成长档案”页面。

讲解重点：

- 学生每次练习都会形成数据沉淀
- 系统不仅给出即时反馈，还能形成长期成长记录

### 第十一步：回到教师端看结果回流

回到教师端：

1. 打开“教学看板”
2. 打开“批阅复盘”

讲解重点：

- 教师端能看到班级平均分、提交率、共性问题
- 教师还能结合 AI 结果继续进行批阅和复盘
- 这样就形成了“教师发布任务 -> 学生提交作业 -> AI 评测 -> 教师复盘”的完整闭环

## 九、如果页面打不开，先检查这 3 件事

### 情况 1：教师端或学生端提示接口错误

先看后端窗口是不是还开着。

只要后端没开，前端就一定拿不到数据。

### 情况 2：浏览器地址打不开

看终端里显示的端口是不是变了。

比如：

- 教师端不一定总是 `5173`
- 学生端不一定总是 `5174`

请以终端实际显示的 `Local:` 地址为准。

### 情况 3：命令运行后没反应

大多数情况是你没有先进入根目录，请重新输入：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
```

然后再执行对应脚本。
