# 答辩当天 6 个终端怎么开（傻瓜版）

## 1. 这份文档怎么用

如果你答辩当天要让：

- 教师端能外网访问
- 学生端能外网访问
- 手机不在同一局域网也能打开

那你就照着这份文档，一个终端一个终端地开，不要自己临场重排顺序。

这份文档默认你用的是：

- Cloudflare Quick Tunnel
- 外网演示版脚本

项目目录默认是：

```text
c:\Users\96967\Desktop\大创\code
```

## 2. 先记住总原则

答辩当天一共要开 6 个终端。

顺序不能乱：

1. 后端服务终端
2. 后端 Tunnel 终端
3. 教师端预览终端
4. 教师端 Tunnel 终端
5. 学生端预览终端
6. 学生端 Tunnel 终端

你只要记住一句话：

先把后端变成公网地址，再让教师端和学生端去用这个公网地址。

## 3. 终端 1：启动后端服务

打开 VS Code 第 1 个终端，执行：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
scripts\03_外网演示\1_启动后端_外网版.cmd
```

这个终端不要关。

成功标志：

- 出现 `Application startup complete`
- 或出现 `Uvicorn running on http://0.0.0.0:8000`

## 4. 终端 2：给后端开公网 Tunnel

打开第 2 个终端，执行：

```cmd
cloudflared tunnel --url http://localhost:8000
```

你会得到一个地址，例如：

```text
https://abc-def-ghi.trycloudflare.com
```

这个地址非常重要。

它就是：

- 后端公网地址

把它复制出来，马上要用。

这个终端也不要关。

## 5. 先暂停一下：修改两个前端的 .env.local

在开第 3 个终端之前，先做这一步。

### 5.1 修改教师端

文件：

- `teacher-web\.env.local`

内容写成：

```env
VITE_API_BASE_URL=https://abc-def-ghi.trycloudflare.com
```

### 5.2 修改学生端

文件：

- `student-app\.env.local`

内容写成：

```env
VITE_API_BASE_URL=https://abc-def-ghi.trycloudflare.com
```

注意：

- 这里必须写刚才终端 2 给你的后端 Tunnel 地址
- 不能写 `127.0.0.1`
- 不能写 `localhost`

## 10. 最后你手里应该有 3 个公网地址

答辩当天你最终要记住的，只有这 3 个地址：

1. 后端公网地址
   作用：前端请求 API
2. 教师端公网地址
   作用：给老师和评委看教师端
3. 学生端公网地址
   作用：给老师和评委看学生端

## 11. 如果只想让手机看页面，最终打开哪个

手机最终只打开两个前端地址：

- 教师端公网地址
- 学生端公网地址

手机一般不需要直接打开后端地址，除非你想演示 Swagger。

## 12. 最容易出错的 4 个地方

### 12.1 前端页面能打开，但登录失败

通常是：

- `.env.local` 没改
- `.env.local` 写成了 `127.0.0.1`
- 写完 `.env.local` 后没有重新启动前端

### 12.2 后端 Tunnel 换了地址，但你没同步改前端

Quick Tunnel 地址可能变化。

如果你重新跑了：

```cmd
cloudflared tunnel --url http://localhost:8000
```

那就要把新地址重新写进：

- `teacher-web\.env.local`
- `student-app\.env.local`

然后重新开教师端和学生端。

### 12.3 只开了前端 Tunnel，没开后端 Tunnel

这样手机虽然能看到页面，但数据会报错。

因为：

- 页面在公网
- 但 API 还在你本机

所以后端 Tunnel 一定要开。

### 12.4 答辩过程中手滑关掉某个终端

只要你关掉以下任意一个窗口，都可能导致外网访问失效：

- 后端服务终端
- 后端 Tunnel 终端
- 教师端 preview 终端
- 教师端 Tunnel 终端
- 学生端 preview 终端
- 学生端 Tunnel 终端

答辩前请全部保持打开。
