## 3. 平时开发点哪个

如果你现在要做的是：

- 改页面
- 改接口
- 本机联调
- 同一局域网内手机调试

直接运行：

- [运行_本地版.cmd](/abs/path/c:/Users/96967/Desktop/大创/code/运行_本地版.cmd)

它会先带你进入本地联调模式。

后续再按顺序开：

1. 后端
2. 教师端
3. 学生端

## 4. 答辩外网演示点哪个

如果你现在要做的是：

- Cloudflare Tunnel 外网演示
- 手机不在同一局域网也能访问
- 答辩现场远程展示

直接运行：

- [运行_外网版.cmd](/abs/path/c:/Users/96967/Desktop/大创/code/运行_外网版.cmd)

它会先带你启动外网版后端，并打印后续外网步骤。

然后你再继续：

1. 开后端 Tunnel
2. 改两个前端 `.env.local`
3. 启动教师端外网版
4. 开教师端 Tunnel
5. 启动学生端外网版
6. 开学生端 Tunnel

- `teacher-web` 跑不起来
- `node_modules` 明显损坏

直接运行：

- [修复_教师端依赖.cmd](/abs/path/c:/Users/96967/Desktop/大创/code/修复_教师端依赖.cmd)

## 6. 现在脚本出错时会更清楚

当前 `.cmd` 脚本已经补了两类改进：

### 6.1 报错更明确

现在会区分告诉你：

- 是 `teacher-web` 安装失败
- 还是 `student-app` 安装失败
- 还是 `package.json` 根本不存在
- 还是入口脚本路径找不到

### 6.2 更适合双击执行

关键入口脚本现在已经补了：

- `pause`

这样双击后即使报错，也不会一闪而过。

## 7. 如果你还想更稳

如果你不喜欢 `cmd` 的中文兼容性，也可以改用 `PowerShell` 版本脚本。

对应目录在：

- `scripts/01_安装与修复`
- `scripts/02_本地联调`

这些目录中同时保留了 `.ps1` 版本。
