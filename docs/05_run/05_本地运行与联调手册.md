# 05_本地运行与联调手册

## 1. 文档目的

这份手册只回答三件事：

- 项目怎么启动
- 前后端怎么联调
- 内网版和外网演示版分别怎么走

如果你是第一次接手这个项目，建议先读这份文档，再决定是走“本地联调版”还是“Cloudflare Tunnel 外网演示版”。

## 2. 当前项目包含什么

当前项目主要分为 4 个部分：

- `teacher-web`
  教师端前端，基于 Vue 3 + Vite
- `student-app`
  学生端前端，基于 Vue 3 + Vite
- `api-server`
  业务后端，基于 FastAPI
- `ai-service`
  AI 服务，当前可作为后续扩展或独立演示模块

项目根目录默认位于：

```text

```

## 3. 先理解两种运行模式

### 3.1 本地联调版

适合：

- 日常开发
- 改页面
- 改接口
- Swagger 联调
- 电脑本机演示
- 同一局域网内的手机调试

特点：

- 前端使用 `npm run dev`
- 后端直接本地运行
- 启动快，改代码后刷新也快

对应脚本目录：

- `scripts/02_本地联调`

### 3.2 外网演示版

适合：

- 大创答辩
- 非同一局域网访问
- 手机外网打开教师端和学生端
- 远程给老师看

特点：

- 后端使用 `0.0.0.0` 对外监听
- 前端使用 `build + preview`
- 通过 Cloudflare Tunnel 把本地服务临时暴露到公网

对应脚本目录：

- `scripts/03_外网演示`

## 8. `.env.local` 什么时候需要改

### 8.1 本地联调版

通常不需要额外改。

如果你只是本机开发，可以继续用：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

### 8.2 外网演示版

必须改成后端公网地址，例如：

`teacher-web/.env.local`

```env
VITE_API_BASE_URL=https://abc-def-ghi.trycloudflare.com
```

`student-app/.env.local`

```env
VITE_API_BASE_URL=https://abc-def-ghi.trycloudflare.com
```

注意：

- 不能写 `127.0.0.1`
- 不能写 `localhost`
- 每次后端 Tunnel 地址变化后，都要重新改一次

## 12. 常见问题排查

### 12.1 后端启动了，但 `/docs` 打不开

先检查：

- 后端终端是否还在运行
- 是否有端口占用
- 是否真的启动在 `8000`

### 12.2 教师端 / 学生端打开了，但接口失败

先检查：

- 后端是否还在运行
- 前端当前读取的 `VITE_API_BASE_URL` 是什么
- 本地版是不是误用了外网地址
- 外网版是不是还写着 `127.0.0.1`

### 12.3 `npm run dev` 或 `npm run build` 报错

先执行：

```cmd
cd /d c:\Users\96967\Desktop\大创\code
scripts\01_安装与修复\2_修复教师端依赖.cmd
```

如果是学生端问题，也可手动删除对应目录的 `node_modules` 后再重装。

### 12.4 外网版页面能打开，但登录失败

通常是：

- 后端 Tunnel 地址变了
- `.env.local` 没同步更新
- 前端改完后没重启
