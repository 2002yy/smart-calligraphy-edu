# Frontend Design Rules

## Layout
- Use grid/flex layout
- Keep alignment consistent
- Avoid clutter

## Visual Style
- Use neutral background (white / light gray)
- Use primary color sparingly
- Add card-style containers

## Typography
- Use hierarchy (title / subtitle / text)
- Avoid long paragraphs
- Keep spacing clean

## Components
- Buttons should be clear and consistent
- Forms should be simple
- Use icons if helpful

## UX
- Prioritize clarity over decoration
- Show important data first
- Keep interaction simple
