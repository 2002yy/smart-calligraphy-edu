# scripts 目录说明

如果你不想先进入 `scripts/` 目录，项目根目录还提供了 3 个入口脚本：

- `运行_本地版.cmd`
- `运行_外网版.cmd`
- `修复_教师端依赖.cmd`

适合：

- 第一次使用项目
- 临时找不到具体脚本时
- 答辩前快速进入对应模式

为了避免“脚本很多但不知道先点哪个”，当前脚本统一分成 3 组：

## 1. 安装与修复

目录：

- `scripts/01_安装与修复`

用途：

- 安装前端依赖
- 修复教师端依赖问题

## 2. 本地联调

目录：

- `scripts/02_本地联调`

适合：

- 本机开发
- 同一局域网调试
- 平时写代码

建议顺序：

1. `1_启动后端_本地版.cmd`
2. `2_启动教师端_本地版.cmd`
3. `3_启动学生端_本地版.cmd`

## 3. 外网演示

目录：

- `scripts/03_外网演示`

适合：

- Cloudflare Tunnel
- 非同一局域网手机访问
- 答辩当天外网展示

建议顺序：

1. `1_启动后端_外网版.cmd`
2. `2_启动教师端_外网版.cmd`
3. `3_启动学生端_外网版.cmd`

注意：

- 外网版前，先把后端 Tunnel 地址写进：
  - `teacher-web/.env.local`
  - `student-app/.env.local`
- 详细步骤见：
  - [Cloudflare Tunnel 外网演示操作稿](../docs/05_run/Cloudflare Tunnel 外网演示操作稿.md)
